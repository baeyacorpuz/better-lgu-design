# Credits

This plugin describes patterns from these community projects. Patterns were adapted and rewritten; no source files were copied, except from Better Naguilian, whose files this plugin starts from.

| Project | Maintainers | License | Patterns |
| --- | --- | --- | --- |
| [Better Naguilian](https://github.com/baeyacorpuz/betternaguilianlu) | baeintech — Bae | MIT | Tokens, components, layout helpers, civic data layer, accessibility checks |
| [BetterSolano](https://github.com/BetterSolano/bettersolano) | Ramon Logan Jr. and contributors | MIT (code), CC BY 4.0 (content) | High-contrast mode, accessibility statement, offline fallback page, service data validation |
| [BetterLB](https://github.com/BetterLosBanos/betterlb) | BetterLB contributors | CC0 1.0 | LGU config file, LGU-type labels, Kapwa token usage, rendered-page token check |
| [betterlocalgov](https://github.com/iyanski/betterlocalgov) | iyanski and contributors | CC0 1.0 | Task-first entry points, service page questions, page owner and last updated date, multilingual support |
| [Kapwa](https://www.npmjs.com/package/@bettergov/kapwa) (`@bettergov/kapwa`) | BetterGov.ph | CC0 1.0 | Token names in the crosswalk (`references/kapwa.md`) |

All of them build on the work of [BetterGov.ph](https://bettergov.ph).
